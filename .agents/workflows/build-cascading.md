# Workflow — Build / Revise Cascading

1. Baca `AGENT_RULES.md`.
2. Temukan node di `knowledge/cascading-jambin-v3-canonical.md`.
3. Verifikasi kode/nama/pengampu.
4. Verifikasi formula dari source resmi bila perubahan substansi dibutuhkan.
5. Tentukan:
   - MANDIRI atau AGREGATIF;
   - relation child;
   - formula key;
   - formula status;
   - input variables;
   - target;
   - aggregation.
6. Jangan memakai keberadaan child sebagai bukti AGREGATIF.
7. Update canonical markdown dahulu.
8. Update seeder/config.
9. Jalankan architecture tests.
10. Laporkan perubahan dan source.
