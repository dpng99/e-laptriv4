# Workflow — Audit Indicator

Untuk satu indikator, jawab:

1. Apa kode dan nama canonical?
2. Siapa pengampu?
3. Apa level?
4. Apakah MANDIRI/AGREGATIF?
5. Jika punya child, apa relation masing-masing?
6. Apa formula resmi?
7. Apa input mentah?
8. Apakah input user atau auto/master/external?
9. Apa target?
10. Apa period mode?
11. Bagaimana agregasi antarunit?
12. Apakah formula dapat direproduksi?
13. Apakah target, realization, achievement terpisah?
14. Apakah UI hanya meminta raw factual input?
15. Apakah test tersedia?

Jika satu poin tidak jelas, tandai sebagai issue; jangan berasumsi.
